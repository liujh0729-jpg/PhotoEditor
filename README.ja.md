# AIPDD PhotoEditor（base Compositor）

[English](README.md) · [简体中文](README.zh-Hans.md) · [Français](README.fr.md) · **日本語** · [العربية](README.ar.md) · [Tiếng Việt](README.vi.md) · [Español](README.es.md) · [Русский](README.ru.md)

Adobe Photoshop は高すぎるし、GIMP のようなツールは馴染めなくて集中が続かない。それで Compositor を作りました。

目指したのは、完全無料でオープンソースの多機能画像エディタです。以前コンポジットやレタッチに Photoshop を使っていたので、Compositor はそのワークフローを中心に設計してあります。最終的にピクセル単位で詰められるだけのツールが揃っています。

オープンソースなので、Xcode プロジェクトをダウンロードして、自分のワークフローに合わせて機能を追加・削除・変更できます。

## インストール

### ダウンロード
[robbietilton.com/compositor](https://robbietilton.com/compositor) から、または [GitHub Releases](https://github.com/robbietilton/Compositor/releases/latest) の最新リリースから直接ダウンロードしてください。

### Homebrew

```sh
brew install --cask robbietilton-compositor
```

## 機能

### レイヤー
- レイヤーとフォルダ。不透明度と Photoshop の全ブレンドモードを同じ順序でサポート。フォルダの不透明度は内部すべてを減光します
- レイヤーマスク：キャンバス上のどこにでも描画・塗り・反転・ぼかし・ぼかし際指定ができ、レイヤー自身のピクセル外にはみ出せます。リンク解除すればマスク単独で変換できます
- クリッピングマスクとフォルダマスク
- 調整レイヤー：色相・彩度、レベル補正、カーブ、露光、グラデーションマップ、グレイン、モノクロ、カラーバランス、反転、ガウシアンブラー、ブレブラー、ノイズ追加
- レイヤー効果：線、ドロップシャドウ、カラーオーバーレイ、内側のシャドウ、外側の光彩、内側の光彩。すべて GPU で描画され、いつでも編集可能
- 下と結合、レイヤーを結合、グループを結合（⌘E）
- 複製、インライン改名、ドラッグ＆ドロップによる並び替えと入れ子、Option ドラッグで複製、レイヤーパネルの右クリックメニュー
- レイヤーやフォルダごとコピー＆ペースト（選択なしで ⌘C/⌘V）。プロジェクト内でもプロジェクト間でも OK。ドラッグで別プロジェクトへも移動可能

### 変形
- 破壊的でない移動、拡大縮小、回転、反転 — 小さくしても画像はフル解像度を保ちます
- 自由変形（⌘ でハンドルをドラッグ）、Shift で軸にロック
- 複数レイヤーやフォルダ全体の同時変形
- キャンバスやレイヤーの縁・中心へのスナップ、ガイド対応
- 位置・サイズ・スケール・角度の正確な値を矢印キーでステップ入力
- レイヤー反転、キャンバス反転（水平・垂直）

### 選択
- 矩形と楕円形選択、なげ魔法な選択、マルチ選択、そしてスマートツール — 魔法の杖は色で選択、オブジェクト選択はクリックしたものをトレース（Tab で切替）
- 被写体を選択。あらゆる選択範囲の拡張、縮小、ぼかし際
- 選択の加算・減算、輪郭移動、中身のピクセル移動・複製
- レイヤーのピクセルやマスクを選択として読み込み
- コンテンツ認識塗りつぶし — 画像を端から外へ延長することも可能

### ペイントとレタッチ
- ブラシ：サイズ、硬さ、不透明度、スムージング。描画と消去（B と E）、Shift で直線
- スポット修復ブラシ（コンテンツ認識）
- コピースタンプ：整列あり／なし、単一レイヤーか全レイヤーからのサンプリング
- ぼかしツール：ピクセルにもマスクにも
- グラデーションツールと図形ツール（矩形、角丸矩形、楕円、直線）。ラスタライズされず編集可能なまま残ります
- 文字ツール（T）：ドラッグ・リサイズ可能な段落ボックスでインライン複数行編集。フォント、サイズ、色、配置、行間はツールヘッダーで。文字も変換でき、クリッピングマスクにも使えます
- スポイトとフルカラーピッカー

### 調整とフィルター
- Camera Raw フィルター：ライト、カラー、カーブ、カラーミキサー、カラーグレーディング、ディテール、オプチクス、ジオメトリをキャンバス横のパネルで。各セクションはヘッダーから既定値に戻せます
- レベル補正（オート付き）、カーブ、色相・彩度、露光、グラデーションマップ、グレイン、モノクロ、カラーバランス、反転
- ガウシアンブラーとブレブラーはレイヤーの外側へも広がります
- ノイズ追加、ヴィネット、ブルーム／グロー、ディザ、スキャンライン、トーンコントラスト、レンズ補正、背景除去
- ライブプレビュー。選択があれば選択内に限定
- 前回フィルター（⌃⌘F）で直前のフィルターを同じ設定で再実行

### キャンバスとファイル
- 複数プロジェクトをタブで
- コマンド検索（⌘F）：Raycast や Obsidian のように、あらゆるメニューコマンドとツールを名前で検索して Enter で実行
- 全画面切替（F）：全面黒背景にキャンバスだけ、全パネルを格納。F か Esc で戻る
- 定規（⌘R）、定規から引くガイド、間隔と细分を調整できるレイアウトグリッド、ガイド・グリッド・レイヤー・ドキュメント境界へのスナップ設定
- スナップ付きトリミング、3:4 や 9:16 を含む比率、Option で左右対称。選択があればそこから始まります
- キャンバスサイズ、イメージサイズ、切り抜き
- 300% 以下のズームではキャンバス隅にナビゲータミニマップ：ドキュメント全体を小さく表示し、現在のビューを枠で示す。クリックやドラッグで移動（表示 › ナビゲータ）
- ズームアウト時は高品質なダウサンプリング、ズームイン時はピクセルグリッド表示
- JPEG、PNG、HEIC、TIFF、WebP、SVG、カメラ RAW（現像ステップが必要）、Photoshop PSD/PSB（8bit RGB、CMYK 非対応）を読み込み。Photoshop のフォルダ、マスク、ブレンドモード、塗り矩形/楕円、単純な横書き文字は編集可能なまま残ります。それ以外のベクターと縦書き文字はピクセル化されます。適用前に変換レポートが表示されます
- 大きなドキュメント：メモリ予算は Mac に応じて変動。開けないほど大きな Photoshop ファイルは、レイヤーをキャンバス範囲に切り落として開きます
- PNG 書き出し（⇧⌘E）、JPEG 書き出し（⇧⌥⌘S）、名前を付けて書き出し（⇧⌥⌘W）で PNG、JPEG、印刷サイズ（拡大縮小可）の 1 ページ PDF。ライブプレビュー、JPEG 品質、ファイルサイズ表示付き。結合コピーも可能
- プロジェクト保存中も作業を続けられます
- Photoshop 風のキーボード-shortcut を全対応。編集 › キーボードショートカットで再割り当て可能
- 数値のラベルをドラッグして値をスクラブ、Photoshop と同じ操作感
- 署名・公証済みの自動アップデート

### AI（自前のゲートウェイを接続）
- AI ゲートウェイ（⌘,）で、あらゆる AI 機能をあなたが信頼する OpenAI 互換サーバーに向けることができます — ホスティングサービスでも、社内プロキシでも、ローカルランナーでも。チャネルには優先度、重み、タイムアウト、オプションの HTTP/HTTPS/SOCKS プロキシ、モデル・パス・チャネル単位の能力別オーバーライドがあり、API キーは macOS キーチェーンに保存され、設定ファイルには入りません。内蔵の AIPDD チャネルが事前設定済みなので、キーを入れるだけで始められます。保存前に「接続テスト」で確認できます
- 能力はエンドポイントの固定値ではなくスロットです：テキストチャット、画像生成、画像編集、動画、音声合成、文字起こし、埋め込み、判断モデルがそれぞれチャネルとモデルを選べます。たとえば画像系はあるプロバイダに、チャットは別のプロバイダに、と振り分けられます
- あらゆる AI アクションはメニューコマンドなので、コマンド検索（⌘F）に出てきて、編集 › キーボードショートカットで再割り当てできます
- 画像生成：テキストから画像を生成。サイズ、品質、スタイル、個数、ネガティブプロンプト付き。結果をキャンバスに新規レイヤーとして置いたり、ディスクに保存したりできます
- 画像編集とインペインティング（画像から画像）：アクティブレイヤーのピクセルとプロンプトをゲートウェイに送り、その場でレイヤーを置換（取り消し可、マスクは保持）するか、結果を新規レイヤーとして追加できます。アクティブレイヤーに有効なマスクがあればそのマスクも送られるので、モデルはあなたがマーカーした箇所だけを編集します
- スタイル転送：参考画像と強度（0〜100%）をゲートウェイに渡し、その色調をアクティブレイヤーに移します
- 自然言語編集：「彩度を上げて」「名空 sky にして」「被写体の選択を解除」「このレイヤーをグループ化」など平易な日本語で編集を指示すると、チャットモデルが構造化インテントを返し、エディタはメニューをクリックした時と同じコードパスで実行します。オフラインではキーワードパーサにフォールバックします。破壊的インテント（削除、ピクセル置換）は実行前に確認します
- セマンティック選択：マスクからキャンバスへのパイプラインは配線済み — ゲートウェイから返るセグメンテーションマスクはレイヤーマスク（白が現像）にも、ピクセル境界を精密にたどる行軍蟻選択にもなれ、レイヤー自身の変換下に置かれます。テキストからマスクを生成するモデル自体はまだプレースホルダで、エンドポイントは SAM 互換サービスを受けられる状態です
- 動画、音声、文字起こしは非同期タスクキュー経由：送信 → 指数バックオフでポーリング → ダウンロード。ポーリングには期限があり、取り消しも尊重するので、ゲートウェイが詰まってもパネルが凍ることはありません。取り消しボタンでタスクをその場で下ろせます
- 設定したチャネル以外はあなたの Mac から何も出ません。アプリはホームコールせず、API キーをバンドルせず、使用量を計測しません

### AI エージェント対応
- AI エージェントやスクリプトがプロジェクトを直接構築・編集できます：`.comp` は PNG レイヤーとマニフェストのフォルダで、開いているプロジェクトは書き込まれるたびにキャンバスがライブで更新されます。[Compositor プロジェクトの書き方](docs/writing-comp-files.md) を参照

## 翻訳

Compositor は 8 言語の UI に対応しています — 英語、簡体字中国語、フランス語、日本語、アラビア語、ベトナム語、スペイン語、ロシア語。AI ゲートウェイ設定 › 一般 で明示的に選ぶこともできます（「システムに従う」にすればシステム環境設定の言語順序に従います）。UI はロケールに追従し、アラビア語は次回起動時に右から左のレイアウトに切り替わります。

文字列カタログは `Compositor/Resources/*.lproj/Localizable.strings` にあります。ロケールごとに 1 ファイル、英語リテラルがキーです。欠落キーは英語ソースに戻るため、半翻訳の状態でも使えます。穴埋めや既存文言の改善の PR は母語話者からのものを歓迎します。新しいロケールを引き受ける場合は、ツールチップなど奥深い場所より、可視面（メニュー、AI シート、ツールヘッダー）から埋めていくのがおすすめです。

## ビルド

`Compositor.xcodeproj` を開いて **Compositor** スキーマを実行してください。

## リリース

`scripts/release.sh` は Release ビルドを作り、Developer ID で署名し、公証・ステープルし、`dist/Compositor-<version>.dmg` に固めます。

次に挙げるものが必要で、いずれもこのリポジトリ外で管理してください：

- ログインキーチェーン内の **Developer ID Application** 証明書
- `xcrun notarytool store-credentials "compositor-notary" …` で保存した公証資格情報
- [`create-dmg`](https://github.com/create-dmg/create-dmg)（`brew install create-dmg`）
